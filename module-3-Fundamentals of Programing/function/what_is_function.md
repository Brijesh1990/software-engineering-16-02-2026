# what is function in c language 

 1. A function is block of code that can be completed any task that called function 

 2. A function are reused  a block of code again and again 

 3. A function is declared it must be called 

 4. A function is always declared with void functionName() in c language    

 5. void return nothing or null 

 6. any function called many times 
 
 **syntax of function**

 ```
  void myFunction()
  {
    //statements 
    int a=5;
    int b=10;
    int c=a+b;
    printf("%d\n",c);
  }

  //call the function 
  int main()
  {
    myFunction();
    return 0;
  }

 ```
