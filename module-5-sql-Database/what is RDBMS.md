# What is RDBMS?

RDBMS (Relational Database Management System) is a type of database management system that stores data in tables (rows and columns) and allows relationships between tables using keys. It uses Structured Query Language (SQL) for defining and manipulating data.

# Advantages of RDBMS

- Data Integrity: Enforces data accuracy and consistency through constraints (primary keys, foreign keys, unique, not null).
- Structured Querying: Powerful and standard query language (SQL) for data retrieval and manipulation.
- ACID Compliance: Supports transactions with Atomicity, Consistency, Isolation, and Durability to ensure reliable processing.
- Data Normalization: Reduces redundancy and improves data integrity through normalization techniques.
- Security: Provides access controls, user authentication, and permissions to protect data.
- Scalability: Can handle growing amounts of data and users (vertical scaling, and some systems support horizontal scaling features).
- Backup and Recovery: Built-in mechanisms for backup, restore, and recovery to protect against data loss.
- Data Relationships: Efficiently represents and enforces relationships between different data entities using foreign keys and joins.
- Standardization and Tooling: Mature ecosystem with many tools, drivers, and integrations for development, reporting, and administration.
